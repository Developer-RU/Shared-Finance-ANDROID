# Security Policy

## Supported Versions

Security fixes are prioritized for the latest development state on `main`.

## Reporting a Vulnerability

Please avoid creating public issues for security vulnerabilities.

Send reports to:
- security@short-finance.local

Include:
- Vulnerability description.
- Reproduction steps or proof of concept.
- Potential impact.
- Suggested fixes if known.

## Response Process

1. Acknowledgement within 5 business days.
2. Triage and severity classification.
3. Patch planning and coordinated release.
4. Public advisory, when appropriate.
